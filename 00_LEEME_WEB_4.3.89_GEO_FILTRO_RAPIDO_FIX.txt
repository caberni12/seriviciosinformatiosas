E-FLEET MANAGEMENT SYSTEM · WEB 4.3.89
HOTFIX · FILTRO RÁPIDO GEO PLANIFICADOR ADMIN

Corrección principal
- El campo “Filtro rápido de Local visitado” del Geo Planificador Admin vuelve a filtrar en tiempo real.
- Buscar por nombre, dirección, código, referencia o ID oculta inmediatamente los Locales no coincidentes.
- La búsqueda ignora mayúsculas/minúsculas y tildes.
- Ejemplo: “casa Alejandro” deja visible Casa Alejandr y oculta los colegios/no coincidentes.
- Los valores Duración, Traslado, Hora objetivo y checks seleccionados no se eliminan por filtrar; solo se ocultan visualmente.
- Al borrar el filtro reaparecen todos los Locales.

Causa corregida
El JavaScript usaba el atributo hidden, pero la regla CSS de .geo-plan-local forzaba display:grid.
Web 4.3.89 aplica ocultamiento explícito display:none!important y una regla CSS de respaldo.
